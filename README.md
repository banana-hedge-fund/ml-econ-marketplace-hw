# Машинное обучение в экономике — домашнее задание

Влияние подключения малого бизнеса к маркетплейсу на месячную выручку фирмы.
Работа на симулированных данных: оцениваем эффект эндогенного подключения к
маркетплейсу с помощью инструментальной переменной (случайная волна приглашений)
и методов причинного машинного обучения. Весь код — на Python (единый язык по требованиям).

## Структура

- `hw.py` — весь код одним файлом: генерация данных (DGP), описательные
  статистики, классификация, регрессия и оценка эффектов воздействия (ATE, CATE,
  LATE), включая параметрическую модель эндогенного переключения (бонус 5.6).
  Воспроизводит все таблицы и рисунки.
- `ДЗ_МО.tex` — текст работы (LaTeX, XeLaTeX, шрифт Times New Roman).
- `figures/` — рисунки для отчёта (создаются скриптом `hw.py`).
- `requirements.txt` — зависимости.

## Запуск

```bash
pip install -r requirements.txt
python hw.py
```

После запуска рисунки появятся в `figures/`, таблицы с результатами — в `tables/`.

## Кратко о методе

Переменная воздействия (подключение к маркетплейсу) эндогенна: на неё и на
выручку влияет ненаблюдаемое качество менеджмента. Поэтому методы на наблюдаемых
признаках (OLS, IPW, AIPW, DML без инструмента) смещены, а инструментальная
переменная (двойное машинное обучение с инструментом) и параметрическая модель
эндогенного переключения корректируют это смещение.
